ChangeLens

Update site p2 per il plug-in Eclipse: barre delle modifiche accanto al codice e autore della dichiarazione a fine riga.

https://simoneplatania.github.io/ChangeLens/

Installazione

  1. In Eclipse: Help > Install New Software…
  2. Add…, incollare l'indirizzo qui sopra come Location.
  3. Selezionare la categoria ChangeLens e proseguire.
  4. Riavviare Eclipse quando richiesto.

Il plug-in non e firmato: Eclipse chiede conferma per il contenuto non attendibile.
